# Tradeline

**Tradeline** is a trading journal for retail crypto traders. You connect your Binance/Bybit/OKX/Bitget accounts with read-only API keys, and it imports your trades
(past history and live ones), groups them into positions, and computes the analytics that help you understand your trading performance and improve it

## Tech stack

 - Backend: Python, FastAPI, SQLAlchemy, PostgreSQL / TimescaleDB
 - Frontend: React, TypeScript, Tailwind CSS
